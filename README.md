## 📌 Project Overview

An end-to-end Machine Learning + Full Stack application for detecting fraudulent insurance claims using predictive analytics.

---

## 🧭 System Architecture

Insurance Dataset → Feature Engineering → Model Training → Flask API → React Dashboard

---

## 🚀 Quick Start

### Train Model
python src/fraud_detection_complete.py

### Build Frontend
cd frontend  
npm install  
npm run build  

### Run Application
python src/flask_api.py

Open http://localhost:5000
